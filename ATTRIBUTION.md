## 2. Pustaka Pemrosesan Citra Lokal (On-Device Vision)

- **MediaPipe Selfie Segmentation**
  - Pembuat: Google LLC
  - Lisensi: Apache License 2.0
  - Dokumentasi: https://developers.google.com/mediapipe
  - Catatan Penggunaan: Berjalan 100% secara lokal pada peramban pengunjung via WebAssembly tanpa mengirimkan data citra ke server eksternal.

Semua bentuk visual lain (elemen kaca, kelopak, mutiara, gelombang, awan, tangga, dsb.) digambar murni menggunakan kode CSS dan HTML5 Canvas API tanpa aset eksternal.
